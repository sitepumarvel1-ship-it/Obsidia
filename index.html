Pengaturan

API key disimpan hanya di browser ini dan dikirim langsung ke penyedianya. Jangan taruh API key di kode atau repo GitHub.

Dengan server gratis milikmu di Cloudflare, jawaban tetap dikerjakan walau Obsidia ditutup, lalu kamu dapat notifikasi saat jawaban siap. Cara membuat server ada di README, bagian "Mode latar belakang".

Di iPhone, notifikasi hanya bisa diaktifkan dari Obsidia yang dibuka lewat ikon di Layar Utama (iOS 16.4 atau lebih baru). Ollama tetap dijawab langsung karena berjalan di komputermu.

    Yakin? Semua chat akan dihapus.

    Obsidia adalah aplikasi chat AI pribadi yang memakai API gratis dari berbagai penyedia. Kamu memilih penyedia dan modelnya sendiri.

    Studio Slide membuat presentasi dengan AI, 10 template, pengatur warna dan font, animasi, lalu mengekspor ke PowerPoint atau HTML. Studio Video membuat video pendek dengan 8 template, animasi teks, transisi, musik, dan narasi, lalu mengekspor ke MP4 atau WebM.

    Fitur lain: banyak penyedia dan model, mode latar belakang dengan notifikasi lewat server Cloudflare gratis milikmu, pindah otomatis saat penyedia penuh, proses berpikir, lampiran gambar dan teks, dikte dan baca suara, proyek, memori, preferensi dan gaya, pratinjau artifact HTML/SVG, edit pesan, bintang, ekspor, serta cadangan dan pemulihan.

    Batasan: kuota gratis tiap penyedia terbatas dan bisa berubah. Kemampuan membaca gambar tergantung model. Data di paket gratis beberapa penyedia (misalnya Google) bisa dipakai untuk melatih AI mereka, jadi hindari mengirim data sensitif.
